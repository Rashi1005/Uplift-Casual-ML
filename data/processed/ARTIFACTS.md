# Processed Artifacts — Documentation

This document describes every file that appears in `data/processed/` during a
complete pipeline run, including its purpose, which CLI command generates it,
and whether it should be committed to Git.

> **Summary rule:** Only documentation files (this file, `archive/README.md`)
> are committed. All generated data files are listed in `.gitignore` and must
> be regenerated locally. See "Regenerating all artifacts" below.

---

## Artifact details

### Raw data

| Artifact | `data/hillstrom.csv` |
|---|---|
| **Generated by** | `python -m src.cli prepare-data` |
| **Size** | ~4 MB (64,000 rows × 12 columns) |
| **Committed** | ❌ No — see `data/MANIFEST.md` for download instructions |
| **Contents** | The original Hillstrom RCT dataset: 8 customer features, `segment` (raw 3-arm treatment), `visit`, `conversion`, `spend` |
| **Reproducible** | ✅ Yes — same source, same schema every download |

---

### Processed splits

These six files are the output of the `preprocess` command. They encode the
features, binarize treatment, and apply the 80/20 stratified split (stratified
on `treatment × conversion`).

| File | Rows | Columns | Description |
|---|---|---|---|
| `X_train.csv` | 51,200 | 17 one-hot | Encoded feature matrix, training set |
| `X_test.csv` | 12,800 | 17 one-hot | Encoded feature matrix, test set |
| `treatment_train.csv` | 51,200 | 1 | Binary treatment indicator |
| `treatment_test.csv` | 12,800 | 1 | Binary treatment indicator |
| `y_train.csv` | 51,200 | 3 | `visit`, `conversion`, `spend` |
| `y_test.csv` | 12,800 | 3 | `visit`, `conversion`, `spend` |

**Generated by:** `python -m src.cli preprocess --seed 42`
**Committed:** ❌ No — reproducible from `hillstrom.csv` with `--seed 42`

---

### Trained models

| Artifact | `baseline_model.pkl` |
|---|---|
| **Generated by** | `python -m src.cli train-baseline --seed 42` |
| **Size** | ~690 KB |
| **Committed** | ❌ No — reproducible |
| **Contents** | Serialised `LGBMClassifier` trained on `X_train` / `y_train["visit"]`, with class weighting. **Target: `visit` (not `conversion`)** — see notebook `03_baseline_model.ipynb` for the documented rationale. |
| **Load with** | `joblib.load("data/processed/baseline_model.pkl")` |

| Artifact | `causal_forest_model.pkl` |
|---|---|
| **Generated by** | `python -m src.cli train-uplift --seed 42` |
| **Size** | ~89 MB |
| **Committed** | ❌ No — too large for Git; reproducible |
| **Contents** | Serialised `CausalForestDML` from econml, cross-fitted on the training set. Estimates individual-level treatment effects (τ̂). |
| **Load with** | `joblib.load("data/processed/causal_forest_model.pkl")` |
| **⚠ Version sensitivity** | This file is sensitive to `econml` version. If you upgrade econml, regenerate by running `train-uplift` again. |

### Evaluation results

All four files are generated together by `python -m src.cli evaluate`.

| File | Contents |
|---|---|
| `phase5_results.csv` | One row per model: `model`, `qini_coefficient`, `ci_lower_95`, `ci_upper_95` |
| `phase5_pairwise_significance.csv` | All model pairs: `model_a`, `model_b`, `ci_lower_a`, `ci_upper_a`, `ci_lower_b`, `ci_upper_b`, `cis_overlap` |
| `phase5_uplift_at_k.csv` | Uplift at k=10/20/30%: `model`, `k`, `uplift_at_k` |
| `phase5_verdict.md` | Human-readable final verdict: best model, statistical conclusions, recommendation |

**Committed:** ❌ No — reproducible with a fixed seed

## Regenerating all artifacts from scratch

After cloning and installing dependencies:

```bash
python -m src.cli prepare-data          # downloads data/hillstrom.csv
python -m src.cli preprocess            # creates the 6 split CSV files
python -m src.cli train-baseline        # trains baseline model, writes ranking
python -m src.cli train-uplift          # trains 3 uplift models (~5 min for Causal Forest)
python -m src.cli evaluate              # Qini metrics, bootstrap CIs, verdict
python -m src.cli simulate              # budget-constrained business impact
```

Or all in one:

```bash
python -m src.cli run-all
```

Use `--skip-if-exists` on any command to skip it if its outputs already exist.

## Naming conventions

| Prefix / suffix | Meaning |
|---|---|
| `X_*.csv` | Feature matrix (rows = customers, columns = encoded features) |
| `y_*.csv` | Outcome columns (`visit`, `conversion`, `spend`) |
| `treatment_*.csv` | Binary treatment indicator (`0` = control, `1` = treated) |
| `*_model.pkl` | Serialised scikit-learn / LightGBM / EconML model object |
| `*_ranking.csv` | Test-set predictions sorted descending by score |
| `phase5_*.csv` / `.md` | Phase 5 (evaluation) outputs |
| `phase6_*.csv` | Phase 6 (business simulation) outputs |
| `run_*.json` / `.jsonl` | Pipeline run metadata |
